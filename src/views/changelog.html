Changelog

1.1.0 (2026.05.07)
  • Added mining to a Jiten SRS deck, mining to preselected deck configurable in settings > mining. This also sets the current sentence as a custom example sentence
  • Added TTS support with 5 voices, configurable in settings > popup
  • Popup can now be resized by dragging the corner and in settings
  • Fixed Mokuro Reader parsing
  • Fixed Aozora Bunko parsing
  • Added support for Yatsu Reader
  • Added support for Nihongo Tracker
  • Slightly changed the styling of the popup buttons
  • Fixed pitch accents on long words overflowing from the popup
  • Various optimisations
1.0.7 (2026.04.02)
  • Added pitch accent graphs (toggleable in settings)
  • Added pitch accent colouring (customisable in theme settings, none by default)
  • Added a button to reveal your API key
  • Added an option to disable the head word link to avoid accidental clicks on mobile
  • Added an option to use long press to trigger the pop-up
  • Fixed the again keybind not working
  • Fixed the forget pop-up closing itself on mobile
  • Fixed the manatan manga parser
  • Fixed the setpoint feature on ttsu (thanks SHIRO-Suit for the PR!)
1.0.6 (2026.03.03)
  • Fixed scrolling in the settings not working on Firefox
1.0.5 (2026.03.03)
  • Revamped the settings page, added a table of content and a search bar
  • Fixed the i+1 sentence display
  • Fixed Jiten Reader breaking Manatan native pop-up for manga
  • Fixed native furigana sometimes breaking up word detection
  • Added an option to open the popup on double tap
  • Changed the changelog to not open on update by default (configurable in settings)
1.0.4 (2026.02.17)
  • Added a new visual theming system in the settings with a few presets. Themes can be be changed instantly from the extension icon and shared simply with a string
  • Fixed a bug where i+1 word styling could get overriden by other states
  • Fixed the layout shifting in ttsu reader
  • Fixed the blacklist/master hotkey not unblacklisting/unmastering
  • Added a new cycle hotkey that cycles between mastered, blacklisted and back to learning
