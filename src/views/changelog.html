Changelog

0.1.4 (2025.12.14)
  • Greatly improved page responsiveness while parsing
  • Fixed status bar UI blocking interaction even when it’s hidden
  • Fixed the UI briefly flashing on F5
  • Added a way to temporarily disable the parsing by clicking the extension icon then enabled to set it to paused
  • Added profiles that can be quickly switched through the extension icon.
  • Added a forget button that permanently removes the word and its reviews.
  • Added an option to change the API endpoint.
0.1.3 (2025.12.07)
  • Fix mokuro parser
0.1.2 (2025.12.07)
  • Added a status bar that shows some stats like the current coverage percentage. You can change its behaviour in the settings such as setting it at the top or bottom, always showing it or only on hover, or hiding it completely unless a keybind is pressed.
  • Fixed new mokuro reader parsing.
  • Added the mastered status. You can change the was it’s displayed with the “mastered” class. It doesn’t get coloured by default.
  • The due word status is now additive: you can have both young and due or mature and due, and apply different CSS classes in that case.
  • Underline is now on the left side by default for vertical text. You can change that by using https://developer.mozilla.org/en-US/docs/Web/CSS/Reference/Properties/text-underline-position.
0.1.1 (2025.11.24)
  • Conjugations is now shown in popup, can be deactivated in settings.
  • Cards are now shown as due when their review date is in the past.
  • Fixed furigana shifting on certain websites.
  • Fixed furigana appearing over the kana in mixed words.
  • The YouTube auto-parser was deactivated since it was broken. You can parse a page manually by clicking the button **BUT** it will only parse what’s shown at the moment, not if you change page etc. Will make a come back in the future.
  • Fixed NHK news / web easy auto-parser not working.
  • Fixed NHK news web easy audio button duplication.
  • Fixed typos on the settings page.
  • Fixed parsing of extra host.
  • Fixed buttons disappearing slower than the pop-up.
0.1.0 (2025.11.17)
  • Initial release with basic functionality.
